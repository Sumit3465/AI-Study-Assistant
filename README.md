## 📌 About the Project

**AI Study Assistant** is an AI-powered web application designed to help students with their everyday learning and study-related queries.

Students often need to search through different websites, notes, books, and resources to understand a single concept. Our project provides an intelligent assistant where students can simply ask their questions and receive relevant, AI-generated responses.

The application combines a user-friendly web interface with a **FastAPI backend** and **Microsoft Azure AI services** to create an interactive and intelligent learning experience.

---

## 🎯 Problem Statement

Students face several challenges during their studies, such as:

- Finding relevant study material
- Understanding difficult concepts
- Getting quick answers to doubts
- Revising topics before examinations
- Searching through multiple sources
- Spending too much time looking for information

To solve these problems, we developed an **AI Study Assistant** that provides students with an easy-to-use platform for asking questions and getting AI-powered assistance.

---

## 💡 Proposed Solution

Our solution is a web-based AI Study Assistant that acts as a digital study companion.

The student can enter a question through the website, and the application processes the query through the backend and AI services.

The system can use **Microsoft Foundry, Foundry IQ, and Azure AI Search** to support AI-powered responses and information retrieval.

🔄 How the Application Works

The application follows the following workflow:
1️⃣ User Input
The student opens the AI Study Assistant and enters a question.  

2️⃣ Frontend Request
The frontend captures the user's question and sends it to the FastAPI backend.

3️⃣ Backend Processing
The FastAPI backend receives the request and processes the user's query.

4️⃣ AI Agent
The backend communicates with the configured Microsoft Foundry AI Agent.
The AI Agent understands the user's query and determines the appropriate response.

5️⃣ Knowledge Retrieval
When required, relevant information can be retrieved using:
Foundry IQ
Azure AI Search
Configured knowledge sources

6️⃣ Response Generation
The AI uses the available information and context to generate a response.

7️⃣ Response Display
The generated response is returned to the frontend and displayed to the student.
